# Conceptual-INGLOURIOUS-BASRERDS-website
Operation Kino — Mission Builder
A cinematic, gamified mission-planning interface inspired by the visual language of Inglourious Basterds.
The app simulates a classified intelligence dashboard where users can create covert operations, register agents, and track high-value targets — all wrapped in a worn parchment, redacted-ink, WWII-era aesthetic.
Features

Mission Builder — define operation name, objective, location, threat level, and a full target profile with photo upload, coordinates, and intel notes
Agent Registration — upload agent photos, assign codenames, statuses, and loadouts
Live Op Board — a real-time overview of the active operation, agent roster, and target surveillance card
Gamified UI details — scanline overlay, pulsing live indicator, classified stamp, animated threat badges, card slide-ins, and button shimmer effects

Design System

Palette: aged parchment, deep crimson, mission-gold, olive ink
Typography: Special Elite · Courier Prime · Oswald
Aesthetic: declassified military dossier meets spy thriller HUD

Built With

React (hooks, state management)
CSS-in-JS with custom properties
Google Fonts

Context
This project is part of Nexera — a personal design challenge where each day takes a film, game, or cultural reference and transforms it into a functional UI/UX concept with a complete design system, case study, and working prototype.
